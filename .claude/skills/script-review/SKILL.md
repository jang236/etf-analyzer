# /script-review <대본 파일 경로> [--brief <brief.md>] [--thumbnail "<썸네일 문장>"]

script-reviewer 에이전트를 단독으로 부른다.

## 절차

1. 대본 파일을 읽을 수 있는지 확인한다. 구글 문서면 먼저 로컬 파일로 저장한다.
2. Agent 도구로 `script-reviewer`를 부른다. 프롬프트에 대본 경로, 있으면 brief와 썸네일 문장, 그리고 "프로젝트 파일이 없는 항목은 입력 없음으로 표시"를 명시한다.
3. 결과를 대본 옆 `<이름>.review.md`에 저장하고, 채팅에는 결과 한 줄과 미달 항목만 표로 보여준다.

## 주의

- 검수 결과를 부풀리지 않는다. 검수기가 통과라고 하면 통과다.
- 수정은 하지 않는다. 수정 지시만 보여주고, 고칠지는 부코드가 정한다.
