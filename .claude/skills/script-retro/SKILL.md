# /script-retro <slug> [--video <영상ID>]

영상 공개 2주 뒤에 돌린다. 그 편에서 부코드가 고른 것(썸네일 구조, 인트로 레퍼런스, 시연 형태, 마무리 유형)과 실제 성과를 한 줄로 묶어서, 몇 편이 쌓이면 "어떤 선택이 성과로 이어졌는지"가 표로 보이게 한다.

## 입력

- `bucode-script/projects/<slug>/script-final.md` 상단 메타 표 (썸네일 문장, 사용 구조, 사용 카드, 마무리 유형)
- 로그 시트 "대본 제작 로그" (`bucode-script/library/production-log.md`): "단계 기록"의 이 프로젝트 줄들, "하이라이트"의 이 프로젝트 줄들
- 데이터 관리 페이지 시트 ID `1vKFjOLIgAzhsc2OVUyaHGrbmqSqqiDU-Qy1Zy0RgYM4`: "영상 링크 관리" 탭에서 영상ID로 행을 찾고, "숏폼 데이터 관리" 탭(조회수, 구독자, 구독전환율)과 "일별 데이터 관리" 탭(공개일 이후 키콘텐츠 조회·클릭률, 랜딩 클릭률)에서 수치를 읽는다
- 비틀리: 이 영상에 쓴 링크의 클릭 수 (bitly_get_link_analytics, 공개일부터 14일)

## 절차

1. 영상ID가 없으면 제작보드의 이 프로젝트 행에서 영상ID를 읽는다. 그래도 없으면 한 줄로 묻는다.
2. 성과 수치를 모은다. 없는 수치는 "필요한 데이터"로 적고 지어내지 않는다.
3. "단계 기록" 탭에 한 줄 append: 일시, 프로젝트, "12 회고", "script-retro", 입력(시트·비틀리), 산출물(수치 요약), 부코드 결정(빈칸), 결과 요약(조회수 N, 노출CTR N%, 키콘CTR N%, 구독전환 N%, 비틀리 N클릭), 메모(공개일, 측정 기간).
4. "하이라이트" 탭에서 이 프로젝트의 줄들을 찾아 "성과" 열에 같은 요약을 채운다 (update_values).
5. 채팅에는 표 하나만 보여준다: 이번 편의 선택 4개(썸네일 구조, 인트로 레퍼런스, 시연 형태, 마무리 유형)와 성과, 그리고 하이라이트 탭에 쌓인 같은 유형의 과거 선택과 성과를 나란히. 질문은 하나: "이 편에서 다시 쓰고 싶은 선택이 있으면 알려주세요." 답하면 그 줄의 "재사용" 열에 "부코드 지정"을 적는다.

## 규칙

- 성과 수치는 시트와 비틀리에서 읽은 값만 쓴다.
- 회고는 한 편에 여러 번 돌려도 된다. 매번 새 줄을 추가하고 측정 기간을 적는다.
