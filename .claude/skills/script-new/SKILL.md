# /script-new <slug>

새 영상 한 편의 작업 폴더를 만들고 브리프를 채운다. 브리프는 파이프라인의 첫 입력값이다.

## 절차

1. `python bucode-script/tools/new_project.py <slug>` 를 실행한다. slug가 없으면 주제를 한 단어로 물어 영문 소문자와 하이픈으로 만든다.
2. 브리프의 결정 항목을 **한 번에 하나씩** 묻는다. 부코드는 한 질문에 한 답을 선호한다.
   1. 영상 역할: 키콘텐츠 / 풀링콘텐츠
   2. 전환 목적: 랜딩페이지 / 무료 상품 / 구독 / 키콘텐츠 유입
   3. 마무리 유형: 고정댓글 유도형 / 구독 유도형 / 신뢰 보강형. 이때 `bucode-script/library/format-ledger.md`를 읽어 최근 4편에 신뢰 보강형이 없으면 그 사실을 한 줄로 알린다.
   4. 채널 키워드 (여러 개 가능)
   5. 본론 뼈대 경로: 레퍼런스 1편 / 8단계 구조
3. 답을 `projects/<slug>/brief.md` 표에 적는다.
4. 뷰트랩과 핫비디오 수집 표는 부코드가 직접 채운다고 안내하고, 채워지면 `/script-pipeline <slug>` 로 이어가라고 한 줄로 말한다.

## 하지 않는 것

- 브리프를 대신 추측해서 채우지 않는다.
- 여러 질문을 한 번에 묻지 않는다.
