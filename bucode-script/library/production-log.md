# 대본 제작 로그 (구글 시트 연동)

기록기와 파이프라인 스킬이 단계마다 구글 시트 "대본 제작 로그"에 줄을 추가한다. 시트 연결이 없는 세션에서는 아래 CSV에만 적고, 다음에 연결된 세션이 시트에 옮긴다.

| 항목 | 값 |
| --- | --- |
| 시트 ID | 1Ml19XOPmGxb_vREffUC8Z8Xi3yh1mr1bXNJzhD7h8sU |
| 링크 | https://docs.google.com/spreadsheets/d/1Ml19XOPmGxb_vREffUC8Z8Xi3yh1mr1bXNJzhD7h8sU/edit |
| 탭 "단계 기록" (sheetId 1) | 단계 하나가 한 줄. 열: 일시, 프로젝트, 단계, 에이전트, 입력, 산출물, 부코드 결정, 결과 요약, 메모 |
| 탭 "하이라이트" (sheetId 2) | 좋았던 선택 하나가 한 줄. 열: 날짜, 프로젝트, 단계, 유형(썸네일/인트로/뼈대/시연/반론/대안/마무리/문장), 내용 한 줄, 왜 좋았나, 재사용 위치(파일·시트 참조), 성과(회고 후 채움), 재사용(부코드 지정) |

## 기록 규칙

- 단계가 끝날 때마다 "단계 기록"에 한 줄을 append 한다 (range `'단계 기록'!A1`).
- 결정 지점에서 부코드가 고른 것은 "부코드 결정" 열에 그대로 적는다. 예: "썸네일 3번", "후보 1, 2 채택", "카드 DC-0927-1 채택, DC-0927-2 실패 사례".
- 같은 단계를 다시 돌리면 새 줄을 추가하고 단계 이름에 "(재)"를 붙인다. 줄을 고치지 않는다.
- 영상별 현황판은 별도로 두지 않고 "레퍼런스 DB"의 🎬제작보드를 쓴다 (bucode-script/library/sheet-map.md). 상태 열을 단계마다 갱신한다.
- 최종 승인 뒤 대본 링크를 채우고, 조회수와 클릭률은 나중에 데이터 관리 페이지에서 가져와 채운다.
- 시트에 쓰지 못한 세션은 아래 CSV 대기열에 같은 열 순서로 적는다.

## 하이라이트 기록 규칙

- 결정 지점을 지날 때마다 부코드가 고른 것을 "하이라이트"에 자동으로 한 줄씩 append 한다. 기획 승인이면 고른 주제·썸네일·뼈대 3줄, 시연 승인이면 채택 카드마다 1줄, 최종 승인이면 종합 반론 문장·대안·마무리 3줄.
- "왜 좋았나"에는 에이전트의 채점 근거나 추천 이유를 적고, 부코드가 답변에 이유를 덧붙였으면 그 말을 그대로 앞에 적는다. 예: "부코드: 이 구조가 내 말투랑 맞음 / 채점: 본질 3, 검증 3".
- 검수에서 한 번에 통과한 블록이 있으면 그 블록의 첫 문장을 유형 "문장"으로 1줄 남긴다.
- "재사용 위치"에는 카드 파일 경로, 구조 레코드 경로, 레퍼런스대본 번호처럼 바로 열 수 있는 참조를 적는다.
- 성과 열은 `/script-retro`가 채우고, 재사용 열은 부코드가 지정했을 때만 적는다.
- 꺼내 볼 때는 `/script-recall <키워드>`.

## 시트 미연결 시 대기열 (CSV)

```csv
일시,프로젝트,단계,에이전트,입력,산출물,부코드 결정,결과 요약,메모
```
