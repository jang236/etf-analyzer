# 수집된 반론

종합 반론에 쓸 시청자의 실제 의심 문장. 레퍼런스 영상과 부코드 영상 댓글에서 수집한다. 출처 없는 문장은 넣지 않는다.

| 날짜 | 반론 문장 | 출처 (영상, 댓글 링크) | 유형 |
| --- | --- | --- | --- |
| 2026-09-18 | 아니, 그건 미국 얘기고 국장은 삼성전자도 휘청이는데? | 부코드 최종 대본에서 예상 반론으로 사용 | 적용 가능성 |
| | 그래서 AI를 100% 믿어도 되나요? | 설계안 본질 질문 | 신뢰 |

유형: 신뢰 / 적용 가능성 / 비용 / 난이도 / 기타
