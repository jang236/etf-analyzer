# 부코드 대본 자동화 시스템

유튜브 대본을 주제 선정부터 완성까지 에이전트 파이프라인으로 만든다. 품질의 일관성은 고정된 검수 기준에서, 창의성은 후보의 폭에서, 부코드의 색깔은 선택에서 나온다. 설계안 원문은 Claude Docs "부코드 대본 자동화 시스템 설계안"이다.

## 빠른 시작

```
/script-new gemini-stock-usage        # 프로젝트 폴더와 브리프 생성
# brief.md에 역할, 마무리 유형, 뷰트랩 수집 결과를 채운다
/script-pipeline gemini-stock-usage   # 단계별로 진행, 결정 지점마다 멈춘다
/script-review bucode-script/projects/<slug>/script-final.md   # 대본 하나만 검수
```

## 폴더

| 경로 | 내용 |
| --- | --- |
| `knowledge/` | 모든 에이전트가 공유하는 기준. 본질, 톤, 구조 규칙, 검수 체크리스트, 전문가 기준, 시연 형태 |
| `templates/` | 브리프, 시연 카드, 구조 레코드, 변환 후보 채점표 |
| `library/` | 축적되는 자산. 시연 카드, 구조 레코드(썸네일/인트로/본론), 시연 형태 장부, 수집된 반론 |
| `projects/<slug>/` | 영상 한 편의 작업 폴더. 단계별 산출물이 번호 순서로 쌓인다 |
| `tools/` | 자막 추출, 프로젝트 생성 스크립트 |
| `../.claude/agents/` | 에이전트 정의 |
| `../.claude/skills/` | 파이프라인 스킬 |

## 사람이 결정하는 지점

1. 브리프: 영상 역할, 전환 목적, 마무리 유형
2. 주제와 썸네일 확정
3. 변환 후보 선택 (5개 중 2~3개)
4. 시연 결과 판정 (채택 / 실패 사례 / 폐기)
5. 본론 뼈대 선택
6. 최종 대본 승인

인트로/본론 경계 확인은 처음에는 승인 단계이고, 10편 연속 수정이 없으면 자동으로 넘긴다.
