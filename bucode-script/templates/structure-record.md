# 구조 레코드: {{kind}} / {{title}}

구조 분석기의 출력이다. 문장을 복사하지 않고 문장의 역할을 저장한다.

| 항목 | 값 |
| --- | --- |
| 종류 | 썸네일 / 인트로 / 본론 |
| 출처 영상 | (제목, 채널, 링크) |
| 배수 | (조회수 ÷ 구독자) |
| 길이 | (분) |
| 수집일 | {{date}} |
| 인트로 경계 | (인트로 마지막 문장) → (본론 첫 문장) |

## 역할 슬롯

| 순서 | 역할 | 원문 (참고용) | 치환 규칙 |
| --- | --- | --- | --- |
| 1 | 예: 비용 감수 → 단 하나의 결론 예고 | "구독료만 수백을 써가면서 깨달은 게 딱 하나 있습니다" | 내 주제에서 감수한 비용과 결론 하나 |
| 2 | 예: 약속 슬롯 | | 본론 골자 핵심 1~2개만 |
