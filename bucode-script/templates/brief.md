# 영상 브리프: {{slug}}

파이프라인의 첫 입력값이다. 주제, 썸네일, 소재 후보는 구글 시트 "레퍼런스 DB"에서 자동으로 가져오므로 여기에 표를 옮기지 않는다.

| 항목 | 값 |
| --- | --- |
| 프로젝트 | {{slug}} |
| 작성일 | {{date}} |
| 제작보드 번호 | (script-new가 채움) |
| 영상 역할 | 키콘텐츠 / 풀링콘텐츠 |
| 전환 목적 | 랜딩페이지 / 무료 상품 / 구독 / 키콘텐츠 유입 |
| 마무리 유형 | 고정댓글 유도형 / 구독 유도형 / 신뢰 보강형 |
| 채널 키워드 | 예: 제미나이 활용법, AI 주식 분석 |
| 본론 뼈대 경로 | 레퍼런스 1편 / 8단계 구조 |
| 목표 길이 | 예: 8~10분 |

## 부코드 직접 지정 (선택)

시트에 없는 영상을 쓰고 싶을 때만 적는다. 비워 두면 시트에서 고른다.
