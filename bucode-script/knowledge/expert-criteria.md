# 전문가 판단 기준

시연 실행기가 AI에게 심어주는 기준이다. 시연 카드의 "해석" 칸은 이 문서를 근거로 쓴다. 이 문서가 채워질수록 "부코드는 늘 이렇게 검증한다"는 인상이 일정해진다.

> 상태: 초안. 대가 3원칙은 최종 대본에서 가져왔고, 재무 수치 기준은 부코드가 채워야 한다 (설계안 열린 질문 1번).

## 대가 3원칙 (버핏, 멍거, 피터 린치 공통)

1. 모르는 회사는 안 산다. 이 회사가 뭘 팔아서 돈 버는지 내 입으로 설명이 돼야 한다.
2. 시장을 예측하지 않는다. 금리와 경기는 내일 오를까를 맞히는 데가 아니라 어떤 산업의 흐름이 좋아질까, 내가 산 회사에 어떤 영향이 올까를 판단하는 데 쓴다.
3. 가격에 집착하지 않는다. 판다는 건 내가 산 이유가 사라졌을 때다. 회사는 멀쩡한데 가격만 빠졌으면 버티거나 더 사고, 가치가 꺾였으면 수익 중이어도 판다.

## DART 3축 해석 틀

시연 카드의 해석은 항상 이 세 칸으로 쓴다.

- 좋아진 것
- 나빠진 것
- 새로 시작한 것

종합 판정은 관심 / 보류 / 제외 중 하나다.

## 재무 기준이 비어 있는 동안의 규칙

- 변환 에이전트와 시연 실행기는 재무 수치의 통과/미달을 쓰지 않는다.
- 정성 기준만 쓴다: 대가 3원칙(설명 가능성, 예측 금지, 이유 기반 매도), DART 3축, 출처 등급(공시·IR > 리포트 > 뉴스 > 블로그)과 출처 날짜.
- 재무 수치가 필요한 후보는 "재무 기준 확정 후 가능"으로 표시한다.

## 판정 문장 규칙

- "이 종목은 좋다"가 아니라 "이 기준으로 보면 부채비율 항목은 통과, 영업이익률은 미달"로 쓴다.
- 기준을 통과했어도 대가 3원칙 1번(설명 가능성)을 먼저 묻는다.
