# 레버리지 시스템

반복 업무를 줄이기 위한 점검표와 자동 루틴의 원본입니다. 실제 결과물은 Google Drive "레버리지 시스템" 폴더에 쌓입니다.

| 파일 | 역할 | 실행 |
|---|---|---|
| `leverage_checklist.csv` | 레버리지 점검표 원본. Drive의 Google 시트로 올라가 있습니다. | 수동 (매주 CEO 회의 때 갱신) |
| `weekly_ceo_prompt.md` | 주간 CEO 회의 문서를 만드는 루틴 지시문 | 매주 월요일 07:45 KST |
| `daily_idea_prompt.md` | ETF 데이터와 뉴스로 콘텐츠 아이디어 5개를 뽑는 루틴 지시문 | 매일 06:53 KST |

## 점검표 계산식

- 주당 절약(분) = 주당 횟수 × 1회 소요(분) × 자동화 비율
- 연간 절약(시간) = 주당 절약 × 52 ÷ 60
- 회수 기간(주) = 구축 시간 × 60 ÷ 주당 절약
- 우선순위 = 회수 기간이 짧은 순

B–F열의 첫 값은 추정치입니다. 1주일 동안 실제 시간을 기록한 뒤 바꾸세요.

## 루틴 지시문을 고칠 때

이 폴더의 `.md` 파일을 고친 뒤, claude.ai의 Routines 화면에서 같은 이름의 루틴 지시문도 똑같이 바꿔야 합니다. 루틴은 이 파일을 직접 읽지 않습니다.
